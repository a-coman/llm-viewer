# llm-viewer
**Paper**: "LLM-based Generation of Realistic and Diverse Domain Model Instances". [ArXiv Preprint](https://arxiv.org/pdf/2604.10350)

**Repository**: Main repository with examples [instagen](https://github.com/a-coman/instagen)

Static site for browsing the object models generated by [llm-instancer](https://github.com/a-coman/llm-instancer) alongside the metrics computed by [llm-evaluator](https://github.com/a-coman/llm-evaluator), [ged](https://github.com/a-coman/ged) and [graphdiff](https://github.com/a-coman/graphdiff). It is part of [instagen](https://github.com/a-coman/instagen).

It is online at https://viewer.a-coman.dev/gpt_5_2.

## Pages
- **Dashboard** (`/<experiment>/`): Simple and CoT metrics side by side for one experiment (`gpt_4o`, `gpt_5_2`), with a radar chart comparing them and per-domain tables.
- **Domain** (`/<experiment>/<domain>/`): metrics for one domain model, GED and GraKeL heatmaps between generations, and Shannon entropy bars.
- **Generation** (`/<experiment>/<domain>/gen<N>`): the class diagram (`.use` and PDF), and the generated instance (SOIL and object diagram PDF) for each Simple run and each CoT category. Also each agent's system and user prompts per attempt, and the LLM-as-a-judge verdict.

## Requirements
- **Node.js 20** and npm for the site.
- **[uv](https://docs.astral.sh/uv/)** to run the Python scripts in `src/scripts`. They only need the standard library, except `random_eval.py` and `judge_random_eval.py`, which declare `openpyxl` inline and uv installs it. This scripts convert the logs and metrics from the dataset into JSON files the site uses. They are run in the `llm-viewer` root, and write to `public/`. They are not needed to run the site, only to add new experiments or regenerate the JSON files for reproducibility.

## Run

To start the dev server locally at `http://localhost:4321` run:

```bash
npm install
npm run dev
```

## Data
The site reads everything from `public/` at build time:
- `public/data/dataset/<MODEL>/<Simple|CoT>/<domain>/<time>/gen<N>/`: generated instances with their PDFs and reports. This are the same as `docs/instances` in instagen.
- `public/data/prompts/<domain>/`: the class diagrams (`diagram.use`, `diagram.pdf`) given to the LLM. This are the same as `docs/models` in instagen.
- `public/*.json`: data the pages use, built from the dataset reports by the scripts below. It includes all metrics obtained from llm-evaluator, ged and graphdiff, and the judge verdicts. The experiments the site builds are listed in `DATASETS` in `src/lib/constants.ts`.

### Rebuilding the JSON files
Run `logs_to_json.py` first. The other scripts read `public/logs.json` to find the experiments.

```bash
uv run src/scripts/logs_to_json.py
uv run src/scripts/metrics_to_json.py
# ... the rest, in any order
```

| Script                  | Reads (from the dataset)                                         | Writes                    |
| :---------------------- | :--------------------------------------------------------------- | :------------------------ |
| `logs_to_json.py`       | `logs.md` per experiment (llm-instancer)                         | `public/logs.json`        |
| `metrics_to_json.py`    | `metrics.md` per experiment (llm-evaluator)                      | `public/metrics.json`     |
| `coverage_to_json.py`   | `simpleCoverage.md`, `cotCoverage.md` (llm-evaluator)            | `public/coverage.json`    |
| `difference_to_json.py` | `simpleDifference.md`, `cotDifference.md`, `combinedDifference.md` (llm-evaluator) | `public/difference.json` |
| `shannon_to_json.py`    | `simpleshannon.md`, `cotshannon.md` (llm-evaluator)              | `public/shannon.json`     |
| `judge_to_json.py`      | `judge-logs.md`, `judge-responses.md`, `judge-results.md` (llm-evaluator) | `public/judge.json` |
| `ged_to_json.py`        | `ged_v2.json` (ged), or the older `ged_wl.md`                    | `public/ged.json`         |
| `grakel_to_json.py`     | `grakel.md` (graphdiff)                                          | `public/grakel.json`      |

To add new results, copy the dataset into `public/data/dataset`, rerun the scripts and add the experiment to `DATASETS` if it is new.

`random_eval.py` and `judge_random_eval.py` sample instances from `logs.json` and `judge.json` into `.xlsx` sheets for the human evaluation of realism and of the judge.

## Deployment
`.github/workflows/deploy.yml` builds the site and deploys it to GitHub Pages on every push to `main`.
